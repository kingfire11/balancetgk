# 🤖 Telegram Bot для проверки баланса tkbk.io

Телеграм-бот для проверки баланса API-ключей сервиса tkbk.io

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Настройка
Откройте `bot.py` и укажите токен вашего Telegram бота:
```python
BOT_TOKEN = "YOUR_BOT_TOKEN_HERE"
```

### 3. Запуск
```bash
python bot.py
```

## 📖 Использование

1. Отправьте боту команду `/start` или `/help`
2. Отправьте ваш API-ключ (начинается с `cr_`)
3. Бот покажет статистику использования

## 📊 Показываемая информация

- Статус ключа (активен/неактивен)
- Общий лимит и остаток средств
- Количество запросов и токенов
- Дневная статистика
- Доступные сервисы

## 🔧 Требования

- Python 3.10+
- python-telegram-bot 20.7+
- requests 2.31.0+
